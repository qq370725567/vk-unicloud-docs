# 云厂商选择攻略

当前 `uniCloud` 支持3个云厂商，分别为 `腾讯云`、`阿里云`、`支付宝云`（按发布的时间排序），那么作为开发者，应该选择哪个云？或者说哪个云最适合我呢？

不废话，直接上结论：（以下结论非uniCloud官方观点，而是vk根据目前云开发用户反馈得出的结论）

___注意：此结论会随着云厂商更新和用户最新反馈而动态调整，当前结论的日期为：2025 年 7 月___

1. 对价格比较敏感的用户选阿里云
2. 对价格比较敏感，但又想要低网络延迟，且不怕折腾的用户选支付宝云+内置数据库（支付宝云的内置数据库有语法兼容性问题）
3. 对稳定性比较看重的用户选腾讯云
4. 对性能和稳定性都比较看重的用户选支付宝云+扩展数据库（扩展数据库具备高性能高可用，且兼容100%语法）

**综合排名（从性能、稳定性、开发体验分析）：**

`支付宝云+扩展数据库` > `阿里云+扩展数据库` > `腾讯云+扩展数据库` > `腾讯云+内置数据库` > `阿里云+内置数据库` ≥ `支付宝云+内置数据库`

**提示：当你的项目选择了一个云厂商后，并不是之后只能用这个云了，也是可以中途搬家换云的，这是uniCloud优势，比如等我项目日活高了，就换支付宝云+扩展数据库等，详见：** [数据库一键搬家工具，支持跨云搬家，跨账号搬家](../db-migration/README.md)
